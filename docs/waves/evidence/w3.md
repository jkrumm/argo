## Decisions and deviations

- **Unprefixed series group.** `paletteOptions.groups` is `SeriesGroup[]` and `groupTokens(name, …)`
  always emits `--vx-<name>-…`, so the old `'': SERIES_MAP` group has no 2.0 spelling. `SERIES` is now
  `groupTokens('series', SERIES_MAP)` (vars `--vx-series-hrv`, …); consumers read `SERIES.*` so nothing
  else changed. `DESIGN.md`'s code sample still shows `seriesTokens` (not an owned file here).
- **Calendar date nav** moved from `PageBar.actions.secondary` to `filtersEnd`: the 2.0 `actions` tuple
  requires a primary first and the date nav has none. m365-explorer's single action became the primary.
- **Per-chart error boundary** around the astro panorama/budget charts dropped with `BasaltErrorBoundary`;
  both are stubs that fetch nothing. Their ports use `ChartCard state={{ error }}`.
- **HyperDX React boundary hook** (`attachToReactErrorBoundary`) dropped with the boundary; the telemetry
  sink is a dev-only `console.debug` stub (Wave 4).
- **Chat liveness** (D2): `hermes-chat/run-liveness.ts` `isLiveRun` (`status === 'submitted' | 'streaming'`) in
  `chat-page.tsx`, `use-hermes-thread-voice.ts`; `hermes-row.tsx` passes `liveStatus={run.status}`, so a
  failed run (`'error'`) stays on the row with its parts. Not exercised against a live failed turn here.
- **Table sorts** (D2): none of the 8 `BasaltDataTable` sites sets a `sortFn`/`sortingFn`, so there was
  nothing to rename.
- **Lint:** 16 findings fixed at source (no suppressions); `docs/poc/**` added to `.oxlintrc.json`
  `ignorePatterns` (AGENTS.md already calls it lint-excluded; the 2.0 preset's `no-explicit-any` error hit it).
  No new `theme-allow` / `oxlint-disable … basalt/`.
- **Peers:** exact font peers 5.2.8 / 5.2.8 / 5.2.7 (argo had 5.3.0), `oxlint ^1.87.0` (1.88 was inside the
  3-day release-age gate), `oxfmt ^0.72.0`.
