Chart Theme Lab

A playground for the proposed Blueprint-based palette. Everything is muted, single-hue, and gray-anchored. Toggle theme and area fill above to compare. The neutrals (background, panels, gridlines, axes) are Blueprint's DarkGray / LightGray ramps — the same system the real dashboard would use.

Four different metrics, four different hues — but one identical design language: same chrome, neutrals, gridlines, gradient treatment, and per-theme shade logic. Different accent, same family. Follows both toolbar controls.

3 · Before / after

Left: today's palette — Ant Design + Material + Tailwind defaults at full saturation, every series shouting. Right: proposed — one hue highlighted, the rest demoted to gray (Datawrapper rule: emphasize 1–2, mute the context). Follows the theme toggle.

4 · Per-theme shade shift

Why series colors can't be a single fixed hex. The hue is constant, but on dark we use a lighter Blueprint shade (no glow/bleed) and on light a deeper one (enough contrast). Same metric, both themes, shown together.

5 · The palette

Blueprint's hand-tuned 5-step ramps are the source. The thin strip under each is a 20-step ramp I generate in OKLCH via color-mix — perceptually even, any resolution, straight from CSS. So I don't need Blueprint's 20-step arrays for gradients/series ramps; see the note.
