## Finance (`fin serve` relay)

`src/routes/finance.ts` relays `/finance/*` to the loopback service `fin serve` (repo `~/SourceRoot/finances`, contract `docs/service.md`) at `127.0.0.1:${FIN_SERVICE_PORT:-4581}` with `Authorization: Bearer ${FIN_SERVICE_TOKEN}` (`op://mini/finances-service/credential`, in `.env.tpl` — launch is fail-closed on it). Map: `GET /finance/status`, `POST /finance/{unlock,lock,sync}`, `GET /finance/sync-runs`, `GET /finance/api/*` (query string passed through), and `POST /finance/api/{transactions/:id/category,transactions/:id/tag,recurring/overrides,merchant-rules}` — exactly those four typed writes (`WRITE_PATHS`; any other POST path is a 400 that never reaches the service), raw body (`parse: 'none'`) capped at 16 KB in bytes (413), forwarded verbatim; a merchant, note or rule pattern in a write body is as private as the vault key (never parsed, logged or traced; the span carries the path only). The service's status and JSON body pass through unchanged (423 locked, 401 wrong key, 429 throttled, 409 sync running); service down, timed out or `FIN_SERVICE_TOKEN` unset → `503 {"error":"finance service unavailable"}`; a service 401 on any path but `/unlock` (our token refused) is also a 503, so the dashboard never reads it as an expired Argo session. **`POST /finance/unlock` carries the vault key**: raw body (`parse: 'none'`, no schema — a failed validation would echo it), forwarded verbatim, never logged, never on a span; `/finance/*` gets no inbound server span (`lib/trace-filter.ts`: the Elysia OTel plugin records `url.full`/`url.query`, i.e. merchants and search terms, and ClickStack is on the VPS); the upstream span carries the path only, with the booking id of `transactions/:id/…` masked as `:id` in span attributes, log lines and error messages, and a failed call's recorded exception is rebuilt from name and message (Bun's connection error carries the full URL, query string included: `TraceOptions.sanitizeError`); logs carry paths and error messages, never query strings or bodies. Human-only: agents never call unlock.
